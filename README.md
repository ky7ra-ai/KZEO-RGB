# KZEO RGB (POCO X8 Pro)

Minimal AMOLED-black / red controller for the back RGB ring (HyperOS + Shizuku).

Features: RGB on/off, color picker (R/G/B sliders + presets), battery-optimization shortcut,
"always on" foreground service (Shizuku).

## Get the APK (no Android Studio needed)
1. Create a new GitHub repository and upload everything in this folder (keep the `.github` folder).
2. Open the **Actions** tab -> **Build APK** -> wait for the green check (about 3-5 minutes).
3. Open the finished run -> **Artifacts** -> download `KZEO-RGB-apk`, unzip it, install `app-debug.apk`.

## Use
Install and start Shizuku, open KZEO RGB, grant the Shizuku permission, then use the switches.
