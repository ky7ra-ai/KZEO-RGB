KZEO RGB

KZEO RGB is an Android utility for controlling and customizing the RGB lighting system on supported POCO devices.

The project is designed to provide a simple way to control the device's built-in RGB lighting without relying on the stock system interface.

Features

- 🌈 RGB color control
- 💡 Enable / disable device lighting
- 🎨 Custom RGB colors
- 🔆 Brightness control
- ✨ Lighting effects
- 📱 Simple and lightweight interface
- ⚡ Designed for POCO devices with supported RGB hardware
- 🔧 Uses Android system/HyperOS lighting interfaces where available

Compatibility

KZEO RGB is primarily developed for POCO devices equipped with controllable RGB lighting, with the POCO X8 Pro/MAX as the main development target.

Hardware compatibility may vary between devices and HyperOS versions.

How It Works

Hololight communicates with the device's internal lighting service to control the RGB hardware.

On supported devices, it utilizes the available HyperOS lighting interfaces to configure colors, effects, brightness, and other lighting parameters.

Project Status

🚧 Development / Experimental

This project is still under active development. Some features may only work on specific POCO models or HyperOS versions.
